# Agent 可复用交互契约 v1

2026-10-13；首个版本已发布 PROD。首个消费者为 ERP 业务助手，后续业务 Agent 复用同一交互层。

## 所有权与边界

Agent 客户端仓拥有视图生命周期、固定窗口/表格组件、会话结果回传与 DSH 适配。Platform 仍拥有身份、主体成员和 Agent 配置。ERP 等业务系统拥有业务字段、表单定义、工具契约、数据、权限、幂等和审计。交互层不访问业务数据库，不签发凭据，不判定业务权限，也不把 Skill 当成授权。无 Schema 迁移或新增公开数据入口。

公共入口暂放在现有 `fs-platform-access` 包的 `interaction` 子入口及 `client` 导出中；独立目录，不新建空包或另一套 Agent Runtime。未来独立打包可保持契约迁移。

## 视图与组件

视图含 `schemaVersion:1`、`module`、`viewId`、`sessionId`、`kind`、`title`、`data`。窗口支持侧边栏和对话框；表格接收业务适配器指定的列和格式化函数。业务适配器提供中文字段、可选对象、校验和操作预览。模型只选择已注册能力，不能发送可执行脚本、HTML、任意 URL 或 DOM 选择器。

Host Registry 保存服务端得出的 owner、有效权限签名、有效期和操作快照；renderer 仅持有不透明 viewId。读取和确认必须先重新取当前业务授权，再比对主体/员工、会话、权限和有效期。确认不得从模型工具直接触发。业务幂等键和引用快照仍由适配器维护。

## 按钮回传

Host 将工具所属的确切运行会话与当前登录身份绑定；退出、切主体或会话销毁后不得向旧会话回传。确认执行成功后，Host 把业务 API 的实际结果作为 plugin 来源消息交给原 DSH Agent，通过既有 `followup` 继续对话。稳定来源 viewId 防止重复点击重复发送结果。

结果回传失败不能改变业务已保存的事实；重试沿用同一结果和业务幂等键。仅发送已遮蔽业务结果，不包含凭据。Agent 收到结果可以总结和继续查询；下一次写入仍需独立预览与用户确认。外部 Agent 维持普通文字契约。

## 验收与发布

验证跨模块/员工/会话拒绝、权限变化/有效期、退出销毁、重复确认与结果去重、回传失败恢复。ERP 首个完整业务验收仍使用正式站系统体验中文合成数据和测试员工；并核对实际窗口、按钮和后续对话。未完成整体验收前不宣告部署。发布分别由 Agent、Platform、ERP 拥有，保留既有版本作为回滚目标。
