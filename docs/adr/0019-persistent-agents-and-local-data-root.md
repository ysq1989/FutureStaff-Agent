# ADR-0019：持久智能体与统一数据根目录

- 状态：已接受（2026-10-11），用户确认；源码开发中，未发布。
- 背景：空白文件夹入口不能表达平台已配置的身份、长期记忆、知识和技能。用户要求模仿 Clawith，在已有智能体下创建会话，并作为 3.0 大版本升级。
- 决定：以平台已有 Agent ID 为入口；会话不可静默切换 Agent。平台共享状态权威不变，本机目录按环境/主体/用户/智能体隔离。新用户采用 LocalAppData 数据根，旧路径保留；不自动把旧会话分配给某个智能体。客户端复用已有 DSH 控制器，只在产品扩展层接入。
- 后果：需要授权目录、受限快照、持久会话绑定、明确同步方向和版本检查。缓存不是权限依据；每次在线操作重新授权。云端工具需要适配，不能执行任意远程脚本。部署、真实数据迁移及发行另行授权。
- 替代关系：补充平台 ADR-0033/0034/0035；客户端历史 decisions 保留，本次及后续新架构记录使用 docs/adr，避免新增竞争编号。实施规格见 ../specs/persistent-agents-v3.md。
